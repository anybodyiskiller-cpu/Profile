# Profile

自用代理软件配置备份与规则整理仓库，主要用于保存经过脱敏处理后的 Surge、Loon、ClashBox、Shadowrocket 等配置文件。

## 推荐点

- 多客户端配置归档：集中整理 Surge、Loon、ClashBox、Shadowrocket 等配置，方便跨设备查看和恢复。
- 公开安全版本：上传内容会移除节点、订阅链接、证书材料、代理链等敏感信息，只保留配置结构、规则和分流逻辑。
- 自动同步备份：本地 iCloud 配置变化后会自动触发同步，并有每天 22:00 的兜底检查。
- 完整性保护：同步前会检查文件是否完整，避免 iCloud 还没同步完就上传空文件或半截配置。
- 规则结构清晰：按客户端分类存放，便于单独引用、对比和维护。

## 目录说明

| 目录 | 说明 |
| --- | --- |
| `Surge/` | Surge 配置与模块相关文件 |
| `Loon/` | Loon 配置文件 |
| `Clashbox/` | ClashBox / Mihomo YAML 配置 |
| `Shadowrocket/` | Shadowrocket 配置备份 |

## 安全说明

这个仓库只保存公开可见的脱敏配置，不包含可直接使用的订阅节点、本地节点、证书私钥或账号凭据。仓库内容更适合作为配置结构参考、规则备份和跨设备恢复索引。
